JAIPUR VIBES - static website (Hostinger ready)
Test locally: open this folder in a terminal and run  python -m http.server 8000  then visit http://localhost:8000/
BEFORE LAUNCH:
1. js/config.js        -> paste real Instagram / Facebook / YouTube URLs (icons stay hidden until set)
2. js/contact.js       -> paste Formspree (or similar) endpoint into FORM_ENDPOINT
3. Replace YOURDOMAIN.com in all HTML, sitemap.xml, robots.txt, .htaccess
4. Replace EMAIL_ADDRESS in the footer and contact page
5. Activate SSL in Hostinger hPanel before enabling the HTTPS redirect
6. Videos: none supplied. Put files in assets/videos/ (see README there)
